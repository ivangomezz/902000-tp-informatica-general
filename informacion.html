Información sobre los/las integrantes y el desarrollo del proyecto.

Es un Trabajo Practico de Informática General 2026 de la UNA. Cátedra: Valeria Drelichman, Pedro Paleo, Leonardo Nadel, Norma Morales.

Con este trabajo se quiere lograr desarrollar, en grupos de dos o tres integrantes, un sitio web interactivo utilizando HTML, CSS y JavaScript. El sitio contiene una colección de tres juegos e integra los contenidos trabajados durante la cursada.

Integrantes:

  • Joaquin Francisco Fernandez.
  • Ivan Gabriel Gomez.
  • Gala Micaela Gutiérrez Basso.

El desarrollo del proyecto se realizó en un entorno de trabajo colaborativo, utilizando herramientas de control de versiones y comunicación en línea para coordinar las tareas y compartir avances.

Esperamos que este proyecto sea entretenido y facil de usar para todos sus usuarios, ya que es un sitio web para el aprendizaje y la práctica.

¡Gracias por visitar nuestro sitio web interactivo!
