Declaración de Uso Crítico de Inteligencia Artificial

En cumplimiento con los criterios de evaluación de la cátedra, se detalla el uso de herramientas de Inteligencia Artificial (Gemini) durante el desarrollo de este parcial:

1. Etapas en las que fue utilizada

Lógica de Programación (JS): Se utilizó asistencia para estructurar los flujos de control e interacción con el DOM, como el manejo del estado y la deshabilitación dinámica de botones durante los turnos en generala.js, la manipulación visual del tablero y la selección de cartas en solitario.js, y la secuencialidad de preguntas y gestión de vidas en trivia.js.

Resolución de Errores (Debugging): Fue clave para depurar la manipulación e integración de llamadas asíncronas a APIs externas (como Deck of Cards API y South Park API), gestionar respuestas de respaldo (fallbacks) locales ante errores de red, y corregir inconsistencias en los estilos CSS e imágenes asignadas dinámicamente mediante JavaScript.

2. Reflexión Crítica

Ventajas: Resultó una herramienta ágil para estructurar esquemas de datos iniciales y resolver de forma eficiente la lógica de estado e integración con APIs externas.

Limitaciones y Aporte Personal: La IA suele presentar imprecisiones en el manejo estricto del DOM, el orden de apilamiento e interacción visual de elementos (CSS/JS) y en el control de rutas relativas de recursos. Fue necesario un trabajo personal riguroso de revisión, prueba y ajuste manual para asegurar el correcto acoplamiento entre la estructura HTML, los estilos y la lógica interactiva de cada juego.
